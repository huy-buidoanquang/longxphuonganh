Đăng nhập

Nội dung thiệp được lưu thẳng vào kho GitHub longxphuonganh, nên cần một mã truy cập GitHub có quyền ghi vào kho này. Mã chỉ lưu trong trình duyệt của máy này.

  1. Mở trang tạo mã của GitHub bằng tài khoản chủ kho.
  2. Repository access: chọn Only select repositories rồi chọn longxphuonganh (và longxphuonganh-khach nếu đã tạo kho riêng tư để đồng bộ danh sách khách, xem tab Khách mời).
  3. Permissions → Repository permissions → Contents: chọn Read and write.
  4. Bấm Generate token, sao chép mã (bắt đầu bằng github_pat_) và dán vào ô dưới.

Nhập danh sách khách

Chọn file Excel (.xlsx) hoặc CSV, hoặc bôi đen các ô trong Excel / Google Sheets rồi dán vào ô bên dưới. Cột đầu là tên in trên thiệp (VD: Anh Huy, Cô chú Tâm). Có thêm cột Bên (Nhà trai / Nhà gái) và Ghi chú thì trang tự nhận.

Danh sách khách mời

Đồng bộ danh sách giữa các máy (làm một lần). Tên khách được lưu trong một kho GitHub riêng tư, chỉ tài khoản của bạn xem được:
  1. Tạo kho mới tên longxphuonganh-khach, chọn Private, bấm Create repository.
  2. Mở danh sách mã truy cập, bấm vào mã đang dùng → Edit → Repository access: chọn thêm longxphuonganh-khach → Update.
Kho longxphuonganh-khach đang để công khai nên chưa đồng bộ (ai cũng xem được tên khách). Mở cài đặt của kho → Danger Zone → Change visibility → Make private.
